# Offline evaluator-assurance examples

These deterministic JSONL artifacts are generated by
`scripts/generate_assurance_examples.py` through the public producer API and
then accepted by the same runtime validator used by `replaydocket migrate`.
They contain synthetic values only and never execute an evaluator, benchmark,
model, agent, provider, or network request.

- `categorical.jsonl` demonstrates errors, abstentions, indeterminate states,
  repeated trials, a critical group, explicitly declared swapped-preference
  invariance, and retained raw plus aggregate anchors.
- `numeric.jsonl` demonstrates exact decimals, repeated-score tolerance, and an
  explicitly declared numeric/tolerance invariance relation.
- `categorical-numeric.jsonl` demonstrates combined judgments and an exact,
  explicitly reviewed context difference/exception.

The examples are teaching artifacts, not acceptance policy. They include no
contract and make no threshold, evaluator-correctness, or label-polarity claim.
Regenerate them with:

```console
python scripts/generate_assurance_examples.py
python scripts/generate_assurance_examples.py --check
```
